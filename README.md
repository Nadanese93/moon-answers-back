Entry for the Make.fun bounty **The Moon Finally Answers Back**
(`u-mang-the-moon-finally-answers-back-781a7ec1`).

One line, in the voice of the Moon replying at last to the wishes, howls
and late-night promises of everyone staring up at it. The Moon answers a
wish for a sign the only way the Moon can — with an eclipse — and humanity
hides indoors and calls it bad luck.

`main.py` writes the exact entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` if unset): a single line, no trailing newline,
validated against the kit gate (UTF-8, 1–240 characters, not only
whitespace).
